# 📘 I Ching – Chinese Wisdom
Digitale Edition des **WV Weltall Verlag e.K.**

Eine minimalistische Flutter‑Anwendung, inspiriert vom *I Ging* (Buch der Wandlungen).

---

## 🧭 Inhalt & Funktionsumfang
- Vollständige Darstellung der 64 Hexagramme  
- Klar strukturierte Texte in ruhiger, minimalistischer Typografie  
- Zufalls‑ und Linienwurf‑Funktion  
- Verlauf & Favoriten  
- Dreisprachige Ausgabe (DE / EN / RU)  
- Vollständig offline nutzbar  
- Keine Werbung, keine Datensammlung  

---

---

## 📦 Installation

### Android
1. GitHub → *Releases*  
2. Datei `i-ching-app-vX.X.X.apk` herunterladen  
3. Auf dem Gerät installieren (Installation aus unbekannten Quellen erlauben)

### Windows
1. GitHub → *Releases*  
2. Datei `i-ching-windows.zip` herunterladen  
3. ZIP entpacken  
4. `i-ching.exe` starten  

> Hinweis: Die EXE benötigt die mitgelieferten DLLs.  
> Bitte **nicht nur die EXE** einzeln herunterladen.
